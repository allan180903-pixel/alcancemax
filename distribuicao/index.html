⬇️   Baixar Instalador para Mac

Passo a passo

1
Abra o Terminal Pressione ⌘ Cmd + Espaço, digite Terminal e pressione Enter
2
Cole o comando abaixo e pressione Enter
curl -fsSL URL_DO_SCRIPT | bash
3
Aguarde a instalação (~2 minutos) O instalador baixa e configura tudo automaticamente
4
Abra o app Clique duas vezes em AlcanceMax.command na Área de Trabalho
⬇️   Baixar Instalador para Windows

Passo a passo

1
Baixe o instalador Clique no botão acima para baixar o arquivo instalar.bat
2
Execute como Administrador Clique com o botão direito em instalar.bat → "Executar como administrador"
3
Aguarde a instalação (~3 minutos) O instalador baixa Python (se necessário) e configura tudo automaticamente
4
Abra o app Clique duas vezes em AlcanceMax na Área de Trabalho
